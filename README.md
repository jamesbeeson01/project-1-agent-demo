# LangChain Agent Project 1 Demo

Welcome to the LangChain Agent Project 1 Demo repository! 

This project demonstrates the setup, configuration, and capabilities of a LangChain-powered agent designed to assist with various tasks, explore documentation, interact with tools, and manage knowledge/memory.

## Features
- LangChain integration
- Tool usage and demonstrations
- Knowledge graph memory integration
- Custom interactive tools (like talking to dogs!)

## Getting Started
Explore the files and tools included in this repository to see how the agent operates.
